# Практична робота 1. Інтернет-магазин

Консольний магазин спорттоварів на Java 21 з Lombok.

Можливості: каталог, кошик, оформлення замовлення зі статусом "Нове", видалення з кошика, історія замовлень, пошук за назвою або категорією.

Запуск: відкрити в IntelliJ IDEA як Maven проєкт і запустити клас com.sukanets.shop.Main.
